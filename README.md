# Zenith ⚡️

### macOS AI & Developer System Manager

> An ultra-lightweight, safety-first macOS system manager designed to inspect and safely reclaim disk space from AI tools, compiler caches, package managers, Docker artifacts, and local LLMs — while keeping your Mac awake during long-running tasks.

---

## 🎯 Philosophy: Clean · Clear · Quiet

- **Clean**: Only safely removable, non-stateful caches and temporary diagnostic logs are targeted. Credentials, keys, configurations, and user data are strictly protected by a hard safety engine.
- **Clear**: Every single candidate is categorized into explicit Risk Tiers (**Safe**, **Rebuild Required**, **Manual Review**), explaining why it can be cleaned and what happens if cleaned.
- **Quiet**: Zero background polling loops when menus or dashboards are closed. 0% idle CPU and 0 background disk I/O.

---

## ✨ Key Features

### 1. 🛡️ Safety Engine & TOCTOU Protection
- **Hard Blacklist**: System roots (`/System`, `/bin`, `/usr`), user homes (`~`), credentials (`~/.ssh`, `~/.gnupg`, `~/.aws`, `~/Library/Keychains`), version control (`.git`), and user content (`Documents`, `Desktop`, `Pictures`, `Music`, `Movies`) can **never** be touched.
- **Symlink Protection**: Symlinks are never traversed into outside boundaries.
- **TOCTOU Guard**: Records filesystem device ID, inode number, and file types during scanning. Re-verifies identity at the microsecond of deletion to prevent race condition attacks or corrupted deletes.
- **Plan-Locked Deletion**: Cleaners only accept cryptographic `DeletePlan`s generated by the Safety Planner. Arbitrary path deletion APIs do not exist in the codebase.

### 2. 🤖 AI Assistant Cache Cleaners
- **Claude Code**: Logs, temporary context buffers, and MCP debug logs (preserves credentials, authentication tokens, and MCP configurations).
- **Cursor**: V8 code cache, GPU shader cache, session logs, and extension zip caches (preserves user settings and keybindings).
- **Gemini CLI & Antigravity**: Temporary scratchpads and prompt caches.
- **Codex, Aider, OpenCode**: Local index caches and temporary files.

### 3. 🛠️ Developer Toolchain & Package Manager Caches
- **Go**: `go-build` compiler object cache and module zip cache.
- **Rust / Cargo**: `~/.cargo/registry/cache`, `~/.cargo/registry/src`, and `~/.cargo/git/checkouts`.
- **Node.js**: `npm`, `pnpm` content-addressable store, `yarn`, and `bun` cache.
- **Python**: `pip` wheel cache and `uv` high-speed package cache.
- **Apple / Xcode**: `DerivedData`, simulator temporary caches, and system Xcode caches.

### 4. 🐳 Docker & Container Inspector
- Inspects local Docker daemon via official CLI / socket integration.
- Categorizes images (dangling vs in-use), BuildKit build cache, stopped containers, and local volumes.
- Safely prunes unused layers with one click without altering running containers or named volumes.

### 5. 🧠 Local LLM Models Manager
- Itemized inventory for **Ollama**, **HuggingFace Hub**, **LM Studio**, and **Apple MLX** models.
- Shows model name, format (GGUF, safetensors, MLX), disk size, and last modified date.
- **Always classified as Manual risk** and never auto-selected for cleaning. Individual models can be reviewed and manually deleted with confirmation.

### 6. 📊 Memory Inspector (Not a "RAM Cleaner" Gimmick)
- Real-time macOS memory pressure gauge (**Normal**, **Warning**, **Critical**).
- Displays Physical RAM, Compressed Memory (macOS in-RAM compression), and Swap usage.
- Top developer process memory breakdown (Cursor, Chrome, Docker, Claude, Node, Xcode).
- **Lifecycle Polling**: Polling timer runs only while the inspector UI is visible; turns off completely when closed.

### 7. ☕ Keep Awake Engine (IOKit Power Assertions)
- Uses native macOS `IOKit` `IOPMAssertionCreateWithName` with RAII `PowerAssertion` structs (automatically drops assertion when finished).
- **App-Triggered Automation**: Automatically keeps Mac awake when long-running tools (e.g. Claude Code, Docker, Terminal) are executing.
- **Quick Manual Timers**: 30m, 1h, 2h, or Indefinite caffeinate mode.

## 🚀 Getting Started

### Prerequisites
- macOS (Apple Silicon arm64 recommended)
- Rust 1.80+ (`rustup`)
- Node.js 20+ and `pnpm` (or `npm`)

### Installation & Development
```bash
# 1. Install frontend dependencies
pnpm install

# 2. Run in development mode (hot reload)
pnpm dev

# 3. Launch full Tauri application
pnpm tauri dev
```

## 🧪 Testing

### Running Rust Backend Tests
```bash
cargo test
```
The test suite validates:
- Hard blacklist rejections (`/`, `~`, `/System`, `~/.ssh`, `~/.aws`, `.git`, `Documents`)
- Symlink traversal safety (zero out-of-boundary traversal)
- TOCTOU verification & abort on inode change
- Unknown signature rejection
- `delete_contents` vs `delete_directory` non-destructive execution
- Docker size parser & memory metrics
- PowerAssertion RAII drop semantics

### Running Frontend Tests
```bash
# Run Vitest unit tests
pnpm test

# Run Svelte & TypeScript type checks
pnpm build
```

## ➕ Adding a New Signature

To support a new developer tool or AI cache, create or edit a `.toml` file under `signatures/`:

```toml
[[signatures]]
id = "dev.mytool.cache"
name = "MyTool Cache"
category = "developer"
risk = "safe" # 'safe' | 'rebuild' | 'manual'
strategy = "delete_contents" # 'delete_contents' | 'delete_directory'
paths = [
    "~/.mytool/cache",
    "~/Library/Caches/mytool"
]
exclusions = [
    "~/.mytool/config.json",
    "~/.mytool/credentials.json"
]
description = "Compiled artifacts and temporary indices."
```
